# StartupWidget
## English
- Want to hide your Windows desktop and keep it clean, but don't like using the Start menu?

**StartupWidget for you!**
### Features
#### Desktop Widget
Here is a widget that can be displayed or hidden!
It can be invoked via hotkeys anytime!

#### App Launcher
If you register, **that's it!** Easily launch your apps anytime!
You can add apps via drag & drop. Supports command Line arguments and UAC freely!

#### Customization
Customize widgets with images and theme colors to make them your own!

#### Multilingual support
It supports English and Japanese.

### Changes from WorkhubForWindows
StartupWidget was completely rewritten from scratch based on the previous app "WorkhubForWindows":
- Upgraded runtime to **.NET 10.0**
- Complete migration to **WPF**

### Environment
- Windows 10 or later
- .NET 10.0 or later

## 日本語
- Windowsのデスクトップを非表示にしてすっきりさせてたい！だけどスタートメニューを使うのが嫌だ！

#### デスクトップウィジェット
表示非表示切り替え可能なウィジェットをここに！ショートカットキーでいつでも呼び出し！

ドラッグ&ドロップでカンタン追加。管理者権限や引数も自由自在！

#### カスタマイズ
使いやすいウィジェットに画像をはめてあなたオリジナルのアレンジを！
テーマカラーもあなた好みに変更可能です
